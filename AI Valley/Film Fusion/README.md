# Film Fusion

Makes a movie poster from a film title and an art style using DALL·E 3.

- **Stack:** OpenAI Images API (`dall-e-3`), Vite
- **Status:** Needs an API key to run. A keyless upgrade is planned (see the [AI Valley README](../README.md)).
