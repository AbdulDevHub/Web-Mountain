How it works

  • On-device first. In desktop Chrome, Lingua uses the built-in Translator and Language Detector APIs. Text never leaves your machine, and each language pack downloads once.
  • Cloud fallback. In other browsers, or for pairs Chrome can't handle, it calls free open-weight models on OpenRouter through a small serverless proxy, so no API key ever ships to the browser.
  • Read aloud. The speaker buttons use your system's voices through the Web Speech API.
