ReAct Agent

Ask anything that needs live facts. The agent thinks, decides which tools to call (weather, Wikipedia, clock, calculator, unit converter), reads the results and answers. Every step is shown.

How it works

  • ReAct loop. The model either calls tools or answers. Tool results go back into the conversation until it has enough to answer (up to 6 steps).
  • Function calling. Tools are described with JSON Schema and run in your browser: Open-Meteo for weather, Wikipedia's API, Intl for time zones, and a hand-written expression parser (no eval).
  • Free models. Calls go through AI Valley's serverless proxy to OpenRouter's free tool-calling models.
