# Scrimba Chatbot

RAG chatbot that answers questions about Scrimba from a knowledge base, with conversation memory.

- **Stack:** LangChain, OpenAI, Supabase vector store, Vite
- **Status:** Needs an API key to run. A keyless upgrade is planned (see the [AI Valley README](../README.md)).

> Started from Scrimba's AI Engineer path, then kept as a learning project.
