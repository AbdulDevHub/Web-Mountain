# Reel Recs (Assistants API)

Movie recommendation chatbot that answers only from a provided movie list, built on OpenAI's Assistants API with file search.

- **Stack:** OpenAI Assistants API, Vite
- **Status:** Needs an API key to run. A keyless upgrade is planned (see the [AI Valley README](../README.md)).

> Started from Scrimba's AI Engineer path, then kept as a learning project.
