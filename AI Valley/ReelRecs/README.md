# ReelRecs

Movie recommendation chatbot that uses embeddings and a Supabase vector store to find relevant movies, then answers with GPT.

- **Stack:** OpenAI Embeddings + Chat API, Supabase (pgvector), Vite
- **Status:** Needs an API key to run. A keyless upgrade is planned (see the [AI Valley README](../README.md)).

> Started from Scrimba's AI Engineer path, then kept as a learning project.
