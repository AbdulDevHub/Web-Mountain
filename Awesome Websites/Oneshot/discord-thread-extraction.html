Discord JSON Chat Cleaner

How to get the Network Response:

  1. Open Discord in your browser and press F12 (Developer Tools).
  2. Select the Network tab.
  3. In the filter box, type messages.
  4. Click into the target DM or channel to trigger a fetch.
  5. Click the request named messages?limit=50.
  6. Open the Response tab, right-click the text, and select Copy Response.
  7. Paste the raw text below and click the button.
